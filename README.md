# Student Record Manager

A simple Python-based Student Record Manager that stores student information in a text file and displays the records in the terminal.

## Features

- Add Student
- Validate Email using Regex
- Save Student Data to a `.txt` file
- Read Student Data from the `.txt` file
- Display Student Records in Terminal
- Handle Invalid Input using Exceptions

## Technologies Used

- Python
- Regular Expressions (Regex)
- File Handling
- Exception Handling
